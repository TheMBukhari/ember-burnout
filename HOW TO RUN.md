# 🔥 Ember: Burnout Assessment

A card-based burnout assessment app. No API key or internet connection required.

---

## ✅ Requirements

- **Node.js** (v18 or later) → https://nodejs.org

That's it.

---

## 🚀 How to Run

### Windows
Double-click **`start.bat`**

### Mac
Double-click **`Launch Ember (Mac).command`**
> If macOS blocks it: right-click → Open → Open

### Linux
```bash
chmod +x start.sh && ./start.sh
```

---

## 📦 First Run Note

The first launch installs dependencies (~30MB). After that, it works instantly offline.

## 🛑 Stopping

Press `Ctrl+C` in the terminal, or close the window.
